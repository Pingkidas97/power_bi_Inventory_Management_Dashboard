# Inventory Management Dashboard using Power BI

## Project Overview
An interactive two-page Inventory Management Dashboard developed using Microsoft Power BI to analyze sales performance, inventory movement, and product trends.

## Dashboard Pages

### 1. Inventory Management Overview
- Total Sales & Order Quantity
- Available Stock Analysis
- Monthly Sales Trend
- Dynamic Inventory Movement
- Top 5 Selling Products

### 2. Product Analysis
- Total Revenue & Units Sold
- Category-wise Sales Analysis
- Top 10 & Least Selling Products
- Brand-wise Sales Analysis
- Monthly Sales Trend

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX Measures
- Data Modeling & Relationships
- Interactive Slicers
- Data Visualization

- Created interactive dashboards.

- Analyzed sales and product performance.
